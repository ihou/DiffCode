为什么做 DiffCode

IDE 也能把改动看得很清楚。只是它把别的也全带上了。

为了看一眼改了什么，代码补全、编译、索引和一堆插件也跟着启动：打开要等，还要占掉几个 GB 内存。AI 和同事写的代码越来越多，这件事你一天要做很多遍。DiffCode 只留下你真正要用的那部分。

精确提交

只提交你想提交的。

取消勾选某一处改动，或者选中几行不提交，这次只提交其余部分；没提交的留在工作区，下次再说。

  • 修改上次提交（Amend）、撤销刚才的提交，⌥⌘K 提交并推送。
  • Git 钩子照常运行，失败时显示原始输出。
  • 回滚整个文件或单处改动，⌘Z 就能找回。

为 coding agent 设计

看着 agent 干活。

在内置终端里跑 Claude Code、Codex 或任何命令行 agent，它改的每个文件都实时出现在上方的 diff 里。

  • 哪行不对直接改，不要的回滚，满意的才提交。
  • ⌥⌘T 把当前文件路径和选中的行号输入终端，直接指给 agent 看。
  • 「与分支比较」一次看完 agent 自分叉以来的全部改动。
分支和历史

分支和历史，点一下就在。

点分支名打开 Git 树：左边分支、标签、远程，右边提交图，用下拉框展示，不额外占一栏。

  • 检出、合并、变基、重命名、删除分支；获取、拉取、推送。
  • 在任意提交上拣选、还原、重置，做完都能撤销。
  • 逐行追溯（Blame）、文件历史、选中几行的历史。
合并冲突

冲突一处一处地解决。

每处冲突上都有「保留 HEAD」「采用传入」「两者都要」。横幅一直显示合并或变基的进度，可以继续、跳过或中止。

所有仓库

所有仓库，一个窗口。

侧边栏列出所有项目，带分支、领先 / 落后数和变更数。把文件夹拖进来，或者运行 dif ~/work/app。

  • ⇧⇧ 随处搜索。
  • 查找文件支持驼峰模糊匹配：cvm 找到 CartViewModel.kt。
  • 基于 git grep 的在文件中查找，可以跨所有项目。

直接改

工作区那一侧可以直接打字，停手约 1 秒自动保存，编码和换行符逐字节保持原样。

并排或单栏

词级高亮、曲线连接带、变更总览条，⌥⌘V 切换视图。

常用语言都有高亮

Kotlin、Java、Swift、TypeScript、Python、Go、Rust、C/C++、C#、Dart 等，还能对比图片。

Stash

暂存本地改动，在列表里应用、弹出或删除，删除也能撤销。

深色或浅色

深色、浅色或跟随系统；代码、界面、终端字号分别可调。

中文或 English

跟随系统，或在设置里选择界面语言。

隐私与安全

你的代码只属于你。

没有账号，没有遥测

只有你获取、拉取、推送时（通过你自己的 git、凭据和 SSH agent），以及检查更新时才会联网。

你不动手，它不写入

刷新、diff、搜索都不写仓库，也不占 index.lock，可以和 IDE、agent 同时开着。

做了都能撤销

回滚、删除、改写历史都能撤销；删除的文件进废纸篓，危险操作先确认。
