Why DiffCode

Your IDE already shows diffs well. It just brings everything else along.

Opening it to see what changed also starts code completion, builds, indexing and a pile of plugins: a long wait and several gigabytes of memory. With agents and teammates writing more of the code, you do that all day. DiffCode keeps only the part you came for.

Features

Everything a review needs. Nothing it doesn't.

Precise commits

Commit exactly what you mean.

Untick a hunk, or select lines and leave them out. Only the rest is committed; what you left out stays in your working tree for later.

  • Amend, undo the last commit, or commit and push with ⌥⌘K.
  • Git hooks run as usual, and their output is shown when they fail.
  • Roll back a file or a single change. ⌘Z brings it back.

Made for coding agents

Watch your agent work.

Run Claude Code, Codex or any command-line agent in the built-in terminal. Every file it touches shows up in the diff above as it works.

  • Fix a line in place, roll back what you don't want, commit what you approve.
  • ⌥⌘T types the current file and selected lines into the terminal.
  • Compare with Branch shows everything since the agent branched off.
History

Branches and history, one click away.

Click a branch name for the Git graph in a dropdown — branches, tags and remotes on the left, commits on the right — without giving up a column.

  • Check out, merge, rebase, rename and delete branches; fetch, pull and push.
  • Cherry-pick, revert or reset any commit, each with Undo.
  • Blame, file history and the history of a few selected lines.
Merge conflicts

Conflicts, one choice at a time.

Every conflict gets Keep HEAD, Take Incoming and Keep Both. A banner keeps the merge or rebase in view, with Continue, Skip and Abort.

All your repositories

Every repository, one window.

The sidebar lists your projects with branch, ahead and behind, and change counts. Drag folders in, or run dif ~/work/app.

  • Search Everywhere with ⇧⇧.
  • Go to File with camel-case matching: cvm finds CartViewModel.kt.
  • Find in Files across all projects, powered by git grep.

Edit in place

Type into the working-tree side. It saves after a second of idle and keeps encoding and line endings byte for byte.

Side-by-side or unified

Word-level highlights, curved connectors and an overview bar. ⌥⌘V switches views.

Syntax for your stack

Kotlin, Java, Swift, TypeScript, Python, Go, Rust, C/C++, C#, Dart and more. Image diffs too.

Stash

Stash local changes, then apply, pop or drop them from a list. Dropping can be undone.

Light or dark

Dark, light or follow the system. Separate font sizes for code, interface and terminal.

Privacy and safety

Your code stays yours.

No account, no telemetry

DiffCode goes online only when you fetch, pull or push — through your own git, credentials and SSH agent — and to check for updates.

Read-only until you act

Refreshing, diffing and searching never write to your repository or take index.lock, so it can stay open next to your IDE and agents.

Everything can be undone

Rollbacks, deletes and history edits come with Undo. Deleted files go to the Trash, and risky steps ask first.
