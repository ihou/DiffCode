DiffCode 0.4.0

新功能

  • 仓库里的仓库。添加一个包含多个独立仓库的文件夹时，DiffCode 会把里面的每个仓库都加进来，不只是最外层那个。.gitignore 忽略的目录不会去找，但被忽略的文件夹如果本身是仓库，仍会加入。子模块和以前一样，跟随所在仓库。
  • 关联工作树。仓库的工作树（git worktree）会自动显示在它下面，各自带分支和改动数，删除后自动消失。DiffCode 只读取，不创建、不删除、不切换。
  • 项目显示为树。侧边栏显示仓库之间的包含关系。折叠一个仓库可以收起它下面的项目，折叠后的那一行仍会统计它们的改动。
  • 刷新时重新查找。在项目上右键选择「刷新」，会重新查找之后新增的仓库和工作树。

New

  • Repositories inside a repository. Add a folder that holds several independent repositories and DiffCode adds each of them, not just the outer one. What .gitignore ignores is not searched, though an ignored folder that is itself a repository is added. Submodules stay with their repository as before.
  • Linked work trees. A repository’s work trees (git worktree) appear under it by themselves, each with its branch and changes, and go when they are removed. DiffCode only reads them: nothing is created, removed or switched.
  • Projects as a tree. The sidebar shows which repository is inside which. Fold a repository to put away what is under it; the folded row still counts their changes.
  • Refresh finds new ones. Right-click a project and choose Refresh to look again for repositories and work trees added since.
