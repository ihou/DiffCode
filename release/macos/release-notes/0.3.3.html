DiffCode 0.3.3

修复

  • 有改动却显示「内容完全相同」。全局 gitattributes 里有 *.a binary 这类规则时，DiffCode 会把改过的文件说成内容完全相同，也标不出改动。现在这些规则不再影响比较。

Fixes

  • Changes shown as “Contents are identical”. With a rule such as *.a binary in your global gitattributes, DiffCode could call a changed file identical and mark none of its changes. Such rules no longer get in the way.
