DiffCode 0.3.2

新功能

  • 字体设置。在设置里可以分别选择代码和终端用的字体。终端提示符里的图标显示成方框时（Powerlevel10k、Starship、oh-my-posh 等用 Nerd Font 画图标），把终端字体换成你装的 Nerd Font，比如 MesloLGS NF。
  • Intel Mac 版。Intel 处理器的 Mac 有了单独的下载，Apple Silicon 版依旧小巧。

What's new

  • Font settings. Pick the font for code and for the terminal in Settings. If the icons in your shell prompt show as boxes (Powerlevel10k, Starship, oh-my-posh and others draw them with a Nerd Font), choose the Nerd Font you have installed, such as MesloLGS NF.
  • Intel Macs. Intel Macs now have a download of their own, so the Apple Silicon one stays small.
