DiffCode 0.2.0

新功能

  • 只提交一部分：在 diff 里按处、甚至按行取消勾选，这次只提交其余的改动，没提交的留在工作区。
  • 分支与远程：检出、新建分支、获取、拉取、推送（推送前先列出要推的提交）；本地改动挡路时，Smart Checkout 先暂存、切换后再恢复。⌥⌘K 提交并推送，⇧⌘K 推送。
  • 合并冲突：列表上方显示正在进行的合并或变基，可以继续或中止；每处冲突可以保留 HEAD、采用传入或两者都要，左边可在 HEAD、共同祖先和传入版本之间切换。
  • 比较任意两个提交：在提交历史或 Git 树里 ⌘ 点选两个提交，右键比较。
  • 拖出文件：从文件树和「本地变更」把文件拖到 Finder、聊天窗口或别的应用。

更轻

  • 启动内存从约 38 MB 降到约 30 MB。
  • 应用体积从约 12 MB 降到约 8 MB。
  • 空闲时不再定时唤醒。

What’s new

  • Commit part of a file: untick changes, or single lines, in the diff to leave them out; they stay in the working tree for a later commit.
  • Branches and remotes: check out, create branches, fetch, pull and push (the commits to push are listed first). When local changes are in the way, Smart Checkout stashes them and brings them back after switching. ⌥⌘K commits and pushes, ⇧⌘K pushes.
  • Merge conflicts: a banner shows a merge or rebase in progress, with Continue and Abort. Each conflict can keep HEAD, take the incoming side, or both; the left side switches between HEAD, the common ancestor and the incoming version.
  • Compare any two commits: ⌘-click two commits in the Log or the Git graph, then right-click.
  • Drag files out of the file tree and the Changes list into Finder, a chat window or any other app.

Lighter

  • Memory at startup: about 38 MB, down to about 30 MB.
  • App size: about 12 MB, down to about 8 MB.
  • No more periodic wake-ups while idle.
