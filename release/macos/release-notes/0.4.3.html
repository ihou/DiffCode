DiffCode 0.4.3

修复

  • 用输入法输入中文。在「在文件中查找」里用输入法打字时，还没选字拼音就可能变成英文字母；写提交说明时，改动列表一刷新，正在输入的拼音也可能丢失。现在选字之前不会打断输入法，组字时按 Esc 也交给输入法处理，不再关闭弹窗。

Fixes

  • Typing Chinese with an input method. In Find in Files, a word typed with an input method could turn into its pinyin letters before a candidate was picked, and pinyin in the commit message could vanish when the changes refreshed. Composing text is now left alone until you pick the characters, and Escape while composing goes to the input method instead of closing the window.
