DiffCode 0.4.2

改进

  • 项目列表下面的分隔线可以自由拖动。项目少时也能拖到最后一个项目下面，留出的空白可以拖入文件夹来添加项目。最多拖到文件树只剩筛选栏；双击分隔线恢复自动高度。

Improvements

  • The divider over the file tree stays where you drag it. With only a few projects it can now go below the last of them, leaving room to drop folders on to add them. It still goes no further than the file tree’s filter bar, and a double-click puts back the automatic height.
