DiffCode 0.3.0

DiffCode 开源了：GPLv3，源码在 github.com/ihou/DiffCode。

新功能

  • 修改上次提交（Amend）：勾选提交框里的「修改上次提交」，可以补文件或只改提交说明；提交已推送时会提醒，改完能撤销。
  • Stash：暂存本地改动；在列表里查看、应用、弹出或删除，删除也能撤销。
  • 拣选、还原、重置：在提交历史和 Git 树的右键菜单里拣选（Cherry-pick）、还原（Revert）、把当前分支重置到某个提交；做完都能在提示里撤销。
  • 分支：重命名、删除（先列出只有它才有的提交，删了能恢复）、合并到当前分支、把当前分支变基到它上面。
  • 强制推送：改写过已推送的提交后，推送会提供「强制推送…」，只用 --force-with-lease，main / master 不提供。
  • 界面语言：设置里可以选跟随系统、English 或简体中文。
  • 「关于 DiffCode」里列出第三方组件的许可声明。

DiffCode is now open source under the GPLv3: github.com/ihou/DiffCode.

What’s new

  • Amend: tick Amend in the commit box to add files to the last commit or just reword it. You are warned when the commit is already pushed, and it can be undone.
  • Stash: stash local changes, then view, apply, pop or drop them from the list. Dropping can be undone too.
  • Cherry-pick, revert and reset from the Log and Git graph menus, each with Undo in the toast.
  • Branches: rename, delete (the commits only that branch holds are listed first, and it can be restored), merge into the current branch, rebase the current branch onto it.
  • Force push: after rewriting pushed commits, Push offers Force Push…, which only uses --force-with-lease and is never offered for main or master.
  • Interface language: choose System, English or Simplified Chinese in Settings.
  • Third-party license notices in About DiffCode.
