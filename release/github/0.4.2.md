**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.2/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.2/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.4.2/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### Improvements

- **The divider over the file tree stays where you drag it.** With only a few projects it can now go below the last of them, leaving room to drop folders on to add them. It still goes no further than the file tree's filter bar, and a double-click puts back the automatic height. (#6)

### 改进

- **项目列表下面的分隔线可以自由拖动。**项目少时也能拖到最后一个项目下面，留出的空白可以拖入文件夹来添加项目。最多拖到文件树只剩筛选栏；双击分隔线恢复自动高度。（#6）

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
