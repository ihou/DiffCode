**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.7/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.7/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.4.7/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### Fixes

- **Sharp text in the terminal.** On a Retina screen, the built-in terminal drew its text at half the screen's resolution, so it looked slightly blurry next to the rest of the window. It is now drawn at the screen's full resolution, and stays sharp when you move the window to another display.

This fix is for the Mac app; the Windows app is unchanged.

### 修复

- **终端文字更清晰。**在 Retina 屏幕上，内置终端只用一半的分辨率绘制文字，看起来比窗口其他地方模糊一些。现在按屏幕的完整分辨率绘制，把窗口拖到另一块屏幕上也保持清晰。

这个修复针对 Mac 版，Windows 版没有变化。

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
