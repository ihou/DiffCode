**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.3.1/DiffCode.pkg) — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip`. Requires macOS 14 or later on Apple Silicon.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.3.1/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### What's new

- **DiffCode for Windows.** The same app, built natively for Windows: side-by-side and unified diffs, line-level commits, history and blame, branches and stashes, merge conflicts, and the built-in terminal (PowerShell or cmd), in English and Chinese, light and dark. The installer is under 4 MB, and the app tells you when a new version is out.
- The welcome screen shows the DiffCode icon.

### 新功能

- **Windows 版。** 同一个 DiffCode，为 Windows 原生构建：并排和单栏 diff、按行提交、历史与逐行追溯、分支与 Stash、合并冲突，以及内置终端（PowerShell 或 cmd），中英文、浅色深色都支持。安装包不到 4 MB，有新版本时应用会提示。安装包没有代码签名，第一次运行时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。
- 欢迎页显示 DiffCode 自己的图标。

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
