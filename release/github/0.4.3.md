**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.3/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.3/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.4.3/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### Fixes

- **Typing Chinese with an input method.** In Find in Files, a word typed with an input method could turn into its pinyin letters before a candidate was picked, and pinyin in the commit message could vanish when the changes refreshed. Composing text is now left alone until you pick the characters, and Escape while composing goes to the input method instead of closing the window. This fix is for the Mac app.

### 修复

- **用输入法输入中文。**在「在文件中查找」里用输入法打字时，还没选字拼音就可能变成英文字母；写提交说明时，改动列表一刷新，正在输入的拼音也可能丢失。现在选字之前不会打断输入法，组字时按 Esc 也交给输入法处理，不再关闭弹窗。这次修复针对 Mac 版。

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
