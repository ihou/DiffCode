**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.3.2/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.3.2/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.3.2/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### What's new

- **Font settings.** Pick the font for code and for the terminal in Settings, on the Mac and on Windows. If the icons in your shell prompt show as boxes (Powerlevel10k, Starship, oh-my-posh and others draw them with a Nerd Font), choose the Nerd Font you have installed, such as MesloLGS NF.
- **Intel Macs.** DiffCode now has a download for Intel Macs, kept separate so the Apple Silicon one stays small.

### 新功能

- **字体设置。** 在设置里可以分别选择代码和终端用的字体，Mac 和 Windows 都有。终端提示符里的图标显示成方框时（Powerlevel10k、Starship、oh-my-posh 等用 Nerd Font 画图标），把终端字体换成你装的 Nerd Font，比如 MesloLGS NF。
- **Intel Mac 版。** Intel 处理器的 Mac 有了单独的下载（`DiffCode-Intel.pkg`），Apple Silicon 版依旧小巧。不确定是哪种？苹果菜单 →「关于本机」：写着「芯片 Apple M…」的是 Apple Silicon，写着「处理器 … Intel …」的是 Intel。

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
