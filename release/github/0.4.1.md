**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.1/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.4.1/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.4.1/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### Improvements

- **A taller project list.** Drag the line between the projects and the file tree to give the projects more room. At the bottom the file tree shrinks to its filter bar; drag back up to reopen it. The height is kept, the list still takes only the room it needs, and a double-click on the line puts back the automatic height. (#6)

### 改进

- **项目列表可以拉高。**拖动项目列表和文件树之间的分隔线，可以给项目列表更多空间。拖到底时文件树只留筛选栏，往上拖即可恢复。高度会记住；项目少时列表仍只占需要的高度；双击分隔线恢复自动高度。（#6）

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
