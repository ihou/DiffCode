**macOS:** [Download DiffCode.pkg](https://github.com/ihou/DiffCode/releases/download/v0.3.3/DiffCode.pkg) for Apple Silicon Macs, or [DiffCode-Intel.pkg](https://github.com/ihou/DiffCode/releases/download/v0.3.3/DiffCode-Intel.pkg) for Intel Macs — signed and notarized by Apple; copies already installed update themselves. Prefer to drag it in? Use `DiffCode.zip` or `DiffCode-Intel.zip`. Requires macOS 14 or later. Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple Silicon, "Processor: … Intel …" is Intel.

**Windows:** [Download DiffCode-Setup-x64.exe](https://github.com/ihou/DiffCode/releases/download/v0.3.3/DiffCode-Setup-x64.exe) — installs for your account, no administrator rights needed; or unzip `DiffCode-windows-x64.zip` and run it. Requires 64-bit Windows 10 (version 1809) or later. The installer is not code-signed, so on first run Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.

### Fixes

- **Changes shown as "Contents are identical".** With a rule such as `*.a binary` in your global gitattributes, DiffCode could call a changed file identical and mark none of its changes, on the Mac and on Windows. Such rules no longer get in the way. (#4)

### 修复

- **有改动却显示「内容完全相同」。** 全局 gitattributes 里有 `*.a binary` 这类规则时，DiffCode 会把改过的文件说成内容完全相同，也标不出改动，Mac 和 Windows 都有这个问题。现在这些规则不再影响比较。（#4）

Checksums are in `SHA256SUMS.txt` (macOS) and `SHA256SUMS-windows.txt` (Windows).
